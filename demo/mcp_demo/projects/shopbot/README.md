# ShopBot (expected limited risk, transparency duties)

A customer support chat assistant embedded in a webshop.

## Honest facts, written before touching TERE4AI

ShopBot is an LLM backed assistant. Site visitors type questions; it answers
about order status, return policy, and product details, and escalates to a human
agent on request or when unsure. It interacts directly with natural persons and
generates text.

It does not make decisions about people. It does not profile, score, or
categorise individuals, performs no biometric processing, and infers no
emotions. It is not used in any Annex III context.

Provider and deployer are the same private company established in the EU.

## Known gap

Nothing in this codebase tells the user they are talking to a machine. That is
deliberate: it is the gap the agent should find through TERE4AI rather than
through a hunch.
