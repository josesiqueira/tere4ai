# Adversarial audit of the live demo, 2026-07-30

> Red-team audit of the running system (HTTP facade plus demo web UI) after the
> demo revamp increment 1 shipped. Four independent adversarial passes, each
> read-only, against a live stack started deliberately WITHOUT model API keys so
> the paid paths could only degrade and no paid call could fire (none did).
> Every headline finding was reproduced by the coordinator before any fix.
>
> Formatting rule: never use em dashes; never use en dashes as a sentence break.

## Method

- Stack under test: facade on port 8008 (keyless, TERE4AI_DEMO_SESSIONS_DIR set
  to tests/fixtures/demo_sessions), web UI on port 3111, published dump
  build-3b753e5e9297.
- Pass A, facade protocol abuse: about 230 hostile HTTP requests (type
  confusion, oversized and hostile unicode payloads, path traversal in several
  encodings, method and content-type confusion, batch cap probing, 50-way
  concurrency, error-hygiene scanning).
- Pass B, browser red team: all five pages driven at 1440 and 375 widths plus
  dark mode, hunting state bleed, race conditions, injection, caveat presence,
  keyboard reachability, and any discrepancy between rendered values and the
  raw envelopes behind them.
- Pass C, honesty-contract audit: the eight contracts of architecture.md and
  USER.md attacked from the outside, including span text compared against the
  frozen snapshot bytes.
- Pass D, demo-script fidelity: docs/DEMO.md walked literally in both run modes,
  every fallback artifact opened, and the fresh-clone question tested.

## What held under attack (verified, not assumed)

- DEC-08 scoping: every banned-term occurrence sat inside an exempt verbatim
  quote field; no system-generated field claimed compliance.
- The non-legal-advice notice was present in every 200 envelope from every free
  endpoint, and on every screen at desktop width.
- HLEG mapping caveat present on every mapping surface except /review, which is
  now fixed (see below).
- Trust split (DEC-13): no model imports in the deterministic path, the
  elicitor never emits a classification, unknown flags are never coerced to
  false.
- Prohibited systems returned zero requirements with the prohibition citation;
  the MoodWatch safety variant abstained (requires_human_review, confidence
  0.5) instead of confidently banning.
- Coverage tiles showed judge-accepted counts (339 norms, 475 alignments), not
  the raw totals (434, 620); the served chain_id matched
  BUILD_CHAIN_CURRENT.txt.
- Session replay served and rendered recorded bytes exactly, masking nothing.
- Span text matched the frozen snapshot bytes exactly (offsets are UTF-8
  character offsets, see the open items below).
- Path traversal was blocked in every form attempted; method and content-type
  abuse produced clean 405s and 422s; 50 concurrent classifications were
  byte-identical apart from timestamps; every 200 response carried a complete
  Section 8 envelope with a status inside the calibrated vocabulary.

## Defects found and fixed

- FIXED (commit 4083fd5) DEMO BLOCKER: a fresh clone could not run the demo in
  dev mode. web/public/ui_data.json is generated and gitignored; the Dockerfile
  built it but DEMO.md's dev setup never mentioned it, and both the coverage and
  review pages read it unguarded, so the landing page and step 1 of the talk
  returned a 500. Fixed in three layers: an npm predev and prebuild hook that
  regenerates it, an honest setup notice in both pages when the file is absent
  (never fabricated zeros), the missing step added to DEMO.md, and guard tests.
  Same root-cause family as the CI break of 2026-07-29.
- FIXED (commit f3ce799) DEMO BLOCKER: no staleness guard on in-flight
  requests. Clicking Classify then switching preset left the previous system's
  verdict on screen above the new system's facts. A request token now guards
  every async setter on the assess page. The same commit fixed a reload that
  reverted to a previously permalinked preset and silently re-classified.
- FIXED (commit f3ce799) The Article 27 FRIA determination was carried in the
  classify envelope, advertised by the CredScore preset button, and rendered on
  the replay page, but never shown on the assess page. It now renders verbatim
  (applicability, rationale, basis-node citations, applies-from with its legal
  status), computed nowhere in the UI.
- FIXED (commit 6867551) Uncaught HTTP 500 on every free POST endpoint when the
  body contained NaN, Infinity, or -Infinity. The crash was inside FastAPI's own
  validation-error handler, which tried to re-encode the non-finite float. A
  validation-error handler now sanitizes non-encodable values and returns the
  same clean 422 shape as every other malformed body.
- FIXED (commit 33fab81) TRACEABILITY: source_trace truncated its excerpt at 500
  characters, cutting mid-word, while reporting the full span offsets and no
  truncation indicator. Article 5(1) is 13,735 characters, so a consuming agent
  received 3.6 percent of the text with nothing to signal it. The answer now
  carries excerpt_truncated, excerpt_chars, and span_chars. The excerpt bytes
  were deliberately left pure rather than appending an in-text marker, because
  excerpt is a declared verbatim-quote field whose no-alteration invariant
  outranks the signalling need.
- FIXED (commit 7d3a417) Caveat and copy defects: the HLEG mapping caveat was
  missing on /review; at 375 px the non-legal-advice notice appeared only at the
  page bottom, so it now also appears compactly in the mobile top bar; a
  prohibited result showed its risk badge beside a generic status pill in a way
  that read as self-contradictory, so the envelope status is now on its own
  labelled line; the keyless degradation message showed raw env var names to the
  audience and now shows an audience-appropriate sentence with the technical
  detail collapsed; DEMO.md's claim that the sibling examples folder held
  "richer, multi-exchange sessions" was false and is corrected; the agent-replay
  fallback screenshot was recaptured against the documented default fixture; and
  .env.example's NEO4J_PASSWORD comment now matches the compose default.

## Open items, recorded not silently dropped

- USER.md promises that prohibited systems return "the prohibition citation and
  violated principles", but no violated_principles field or copy exists
  server-side or in the UI. No over-claim is made anywhere today, so this is an
  unimplemented promise rather than a defect. See the task board.
- The non-legal-advice notice text is hardcoded independently in the backend
  constant, the .well-known payload, and twice in the web layout. They are
  byte-identical today with no test asserting it, a latent drift risk.
- source_trace and the span endpoint report UTF-8 character offsets, not byte
  offsets, and the payload does not say so. Naive byte-slice verification by a
  consumer would produce a false mismatch.
- Duplicate top-level JSON keys resolve last-key-wins by standard JSON parsing,
  with no rejection or warning. Not exploitable, noted for consumers.
- A very long description balloons the permalink URL past what some external
  tools accept.
- The classification card still binds an EvidenceGraph to a structurally empty
  subgraph, so it renders nothing; the real graphs come from per-norm alignment
  merges. Tracked as part of the envelope-schema work.
