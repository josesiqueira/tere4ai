# Adversarial audit runbook (repeatable)

> How to re-run the live-demo adversarial audit that produced
> docs/AUDIT_2026-07-30.md. Written so a fresh session with no memory of the
> previous run can repeat it faithfully and compare results.
>
> Formatting rule: never use em dashes; never use en dashes as a sentence break.

## Preconditions

  suite 594 passed and 11 skipped, ruff clean, traceability, release hygiene,
  and the web-copy honesty gate (tests/unit/test_web_copy_honesty.py, 9 tests)

## Start the stack (keyless, so no paid call can fire)

From the repo root:

```
OPENAI_API_KEY= ANTHROPIC_API_KEY= \
TERE4AI_DEMO_SESSIONS_DIR=/home/jose/Dev/Trustworthy/tere4ai2/tests/fixtures/demo_sessions \
.venv/bin/python -m uvicorn --factory tere4ai.http_facade.app:create_app --port 8008
```

```
cd web && npm run dev -- --port 3111
```

Blank keys are deliberate: the paid endpoints (/api/elicit, /api/evidence,
/api/backlog) must then return 503 and never spend money. Wait for readiness
with `curl -sf http://localhost:8008/api/health` and
`curl -sf http://localhost:3111/`. Stop both when finished.

## The four passes

Run them as four independent read-only agents. Rules for every agent: no repo
edits, no commits, scratch files only under the session scratchpad, never
trigger a paid call, and treat any 200 from a paid endpoint as a critical
finding to report immediately (it means real money was spent). Exactly ONE
agent may use the browser tools; the others work over HTTP and by reading
source, otherwise they fight over the single shared browser.

- Pass A, facade protocol abuse (no browser): enumerate real routes from
  /.well-known/tere4ai.json and /llms.txt, then attack every endpoint with
  missing and null bodies, wrong types, empty and enormous strings, deeply
  nested JSON, duplicate keys, non-finite literals, hostile unicode
  (homoglyphs, zero width, RTL override, null bytes, emoji), path traversal in
  several encodings against /api/demo/sessions/{name} and /api/span/{id},
  batch cap probing, method and content-type confusion, 50-way concurrency and
  determinism comparison, and scan every response for leaked absolute paths,
  tracebacks, or a status outside the calibrated vocabulary.
- Pass B, browser red team (owns the browser): all five pages at 1440 and 375
  widths plus dark mode. Hunt state bleed between presets, in-flight race
  conditions, reload and permalink behavior, rapid and double interactions,
  content injection, caveat presence at both widths, keyboard reachability, and
  any discrepancy between a rendered value and the raw envelope behind it.
- Pass C, honesty contracts (no browser): attack the contracts of
  architecture.md and USER.md from outside, including comparing served span
  text against the frozen snapshot bytes (remember offsets are UTF-8 character
  offsets, not byte offsets), banned terms classified by field class against
  VERBATIM_QUOTE_FIELDS, prohibited yielding zero requirements, the safety
  variant abstaining, and coverage counts being the judge-accepted ones.
- Pass D, demo-script fidelity (no browser): walk docs/DEMO.md literally in
  both run modes, verify every on-screen claim against live output, open every
  fallback artifact, and test the fresh-clone question for anything generated
  or gitignored.

Then, as coordinator: reproduce every headline finding yourself before fixing
anything, and fix in passes (demo blockers, then correctness, then copy and
caveats), each pass ending with all gates green.

## Watching CI correctly

A wrapper's exit code is not CI's verdict. Resolve the run id from the commit,
then read GitHub's own conclusion:

```
gh run list --repo josesiqueira/tere4ai --commit <sha> \
  --json databaseId,status,conclusion --jq '.[0] | [.databaseId, .status, .conclusion] | @tsv'
```

The python job generates ui_data.json before pytest and the web job generates
it before the build; the npm hook (web/scripts/ensure-ui-data.mjs) must stay
portable across a local .venv, TERE4AI_PYTHON, and system python, and must
never fail a build when usable data already exists.
